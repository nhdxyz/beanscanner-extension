Information and Help

How to use

When on sites like Dexscreener or Photon, you can use the extension to automatically analyze or try to purchase based on the set bot.

Hotkeys

Use CTRL-SHIFT-Y to analyze and CTRL-SHIFT-O to buy (CMD-SHIFT for mac).

Discord Webhook

If you have the Discord webhook set, it will also send the analyzed coin data to your webhook in an easy-to-view embed.

Right-click Menu

You can analyze or buy by right-clicking a selected token address and choosing the appropriate option from the context menu.

Disclaimer

Your Discord webhook is only stored locally. Always check the token links before buying and never connect your wallet to anything unless you're 100% sure it's a legit site. Sometimes the generated data is not 100% correct. This is only a tool to try to make it easier, but you should still make sure to do your own research.
